# Sources

This skill is written in its own words from the sources below. Where an idea belongs to someone,
the reference files name them.

## Knowledge repositories studied

- [saschb2b/skills](https://github.com/saschb2b/skills) (MIT): a game design skill with references on
  frameworks, principles, patterns, systems, critique, interface, onboarding and accessibility.
- [saschb2b/game-mechanics](https://github.com/saschb2b/game-mechanics): mechanics of well-known
  games, explained one by one.
- [Donchitos/claude-code-game-studios](https://github.com/Donchitos/claude-code-game-studios) (MIT):
  studio roles as agents (game, systems, economy, UX, art, level and live-ops designers) and genre
  "chipsets" (survival-crafting, sandbox, mining).
- [hzoo/awesome-gametalks](https://github.com/hzoo/awesome-gametalks): a list of game talks with links.
- [zilize/gdc-index](https://github.com/Zilize/gdc-index): an index of recent GDC sessions by track.
- [nucleartide/gamedevlectures](https://github.com/nucleartide/gamedevlectures): notes on game dev lectures.
- [munificent/game-programming-patterns](https://github.com/munificent/game-programming-patterns):
  the book *Game Programming Patterns* by Robert Nystrom.
- [Roblox/creator-docs](https://github.com/Roblox/creator-docs): production pages on core loops,
  onboarding, UI and UX, retention, monetization and season passes.
- [ashes999/pixel-artist-training](https://github.com/ashes999/pixel-artist-training) and
  [siilwyn/awesome-pixel-art](https://github.com/Siilwyn/awesome-pixel-art): pixel art curricula and resources.

## Books and essays behind the ideas

Koster, *A Theory of Fun*; Schell, *The Art of Game Design*; Swink, *Game Feel*; Hodent, *The
Gamer's Brain*; Nystrom, *Game Programming Patterns*; Adams and Dormans, *Game Mechanics: Advanced
Game Design*; Rigby and Ryan, *Glued to Games*; Azzi, *Pixel Logic*; Hunicke, LeBlanc and Zubek,
*MDA*; Cook, *Loops and Arcs* and *The Chemistry of Game Design*; Juul, *Half-Real*.
